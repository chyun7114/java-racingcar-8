# 자동차 경주

---
### 기능 요구 사항
- [x] 사용자는 각 자동차에 이름을 부여할 수 있다
  - [x] 자동차 이름은 쉼표(,)를 기준으로 구분한다.
    - [x] 쉼표(,)가 아닌 다른 구분자가 들어오는 경우 잘못된 입력으로 간주한다.
    - [x] 공백 문자가 들어와도 잘못된 입력으로 간주한다.
  - [x] 단, 자동차의 이름은 5자 이하만 가능하다.
- [x] 사용자는 자동차가 몇번의 이동을 할 것인지 입력이 가능하다.
  - [x] 몇 번의 이동을 할 것인지는 양의 정수여야 한다.
- [x] 자동차는 앞으로 전진 할 수 있다.
  - [x] 전진하는 조건은 0에서 9사이에서 무작위 값을 구한 후, 그 값이 4 이상인 경우 이동 가능하다.
  - [x] 한번의 전진에 1칸씩 이동한다.
- [x] 자동차 경주 게임을 완료한 후 누가 우승했는지 알려준다
  - [x] 우승자는 가장 멀리 전진한 자동차로 한다.
  - [x] 우승자가 여러명일 수도 있다.
    - [x] 우승자가 여러명인 경우, 쉼표(,)를 이용하여 구분한다.
- [x] 위의 모든 경우에서 사용자가 잘못된 입력을 할 경우 IllegalArgumentException을 발생시킨다.
  - [x] 그 후, 애플리케이션은 종료되어야 한다.

### 프로그래밍 체크 리스트
- [x] indent(인덴트, 들여쓰기) depth를 3단계 이상 사용하지 않는다.
- [x] 3항 연산자를 쓰지 않는다
- [x] 메서드가 한 가지 일만 잘 하도록 구현한다.
- [x] 정리한 기능 목록이 정상적으로 작동하는지 테스트 코드를 작성한다
- [x] 테스트 코드는 JUnit 5와 AssertJ를 이용한다.
- [x] 자바 코드 컨벤션을 지키면서 프로그래밍한다.

### 커밋 컨벤션 및 규칙
커밋 컨벤션은 다음과 같은 규칙으로 사용한다.

```plaintext
 feat: 새로운 기능 추가
 fix: 버그 수정
 docs: 문서 수정
 refactor: 코드 리팩토링
 test: 테스트 코드 작성 및 수정
 chore: 기타 변경사항(빌드 업무 수정, 패키지 매니저 설정 등
```
